RAG + Agents

LLM को सही जानकारी सही वक्त पर कैसे दें, और ये तरीका कहाँ टूटता है। Lessons इन चीज़ों को एक-एक करके बनाते हैं: retrieval, vectors, probability, RAG model और chunking। फिर BM25, DPR, retriever को नापना, hybrid search और ColBERT। आख़िर में agentic RAG, Search-R1 और RAG की failures।

ये lessons किसके लिए हैं

Lessons मानते हैं कि आप code पढ़ लेते हैं और school का गणित जानते हैं, लेकिन ML और statistics के शब्द आपके लिए नए हैं। इनमें कोई analogy नहीं है। हर idea को उसी असली system के छोटे version पर समझाया है, जैसे 3 passages और 4 numbers वाले vectors। इससे हिसाब हाथ से हो सकता है।
