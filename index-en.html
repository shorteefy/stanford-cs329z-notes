These are self-study lessons built on the lectures of the Stanford course CS 329Z “Engineering AI Agents”. Every lesson starts from first principles. Each new term is explained where it first appears, and each formula is first worked by hand on small numbers.

Who these lessons are for

The lessons assume you read code and know school maths, but that ML and statistics terms are new to you. There are no analogies. Each idea is explained on a small version of the real system, such as 3 passages and vectors of 4 numbers, so the arithmetic can be done by hand.

How to read

  • Open the lecture's index. Its map shows what to read before each lesson.
  • Each lesson starts with a ladder. If you already know a step, skip to the next one.
  • Work out the “Think first” questions yourself before opening the answer.
  • Click any word with a dotted underline and ▾. Its definition opens right there.

How these lessons were written

The lessons follow a fixed set of rules, and each rule rests on research about teaching and writing. Every number was recomputed by a script. Read the full method: the teaching rules, their sources, and how each lesson was checked.
