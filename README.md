# Stanford CS 329Z notes

Unofficial self-study notes on the Stanford course CS 329Z "Engineering AI Agents" (Diyi Yang).

Lecture 3, "RAG + Agents", is covered in 18 lessons. Every lesson has four versions:
Hindi and English, each at an easy level and a dense level that reaches the depth of the lecture slides.

Live site: https://stanford-cs329z-notes.vercel.app

This is a static site. Open `index.html` in a browser, or serve the folder with any static file server.

The slides, and the papers they cite, belong to their authors.
